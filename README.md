# 🏛️ ClubHub | Vijayawada Community Portal

ClubHub is a premium, high-engagement community discovery platform designed for the modern social fabric of Vijayawada. Built with an **"Editorial GenZ"** aesthetic, it combines neo-brutalist design with fluid 3D interactions to connect local clubs with their future members.

![Hero Preview](https://images.unsplash.com/photo-1523580494863-6f3031224c94?q=80&w=1000&auto=format&fit=crop)

## ✨ Core Features

-   **3D Discovery Wheel**: A perspective-linked horizontal carousel for exploring club categories.
-   **Smart Directory**: Verified database of 47+ local clubs with real-time filtering and search.
-   **Editorial Aesthetics**: Premium typography (`Fraunces` & `Unbounded`) and a vibrant "Electric" color palette.
-   **Interactive UI**: Velocity-sensitive scroll progress, magnetic buttons, and glass-brutalist components.
-   **Secure Auth**: JWT-based authentication with Google Sign-In integration.
-   **Social Pulse**: Real-time trending indicators and community stats.

## 🛠️ Technology Stack

-   **Frontend**: React (Vite), Framer Motion (Animations), Lucide React (Icons).
-   **Backend**: Node.js (Express), SQLite (Database).
-   **Security**: Helmet, Express Rate Limit, JWT, Bcrypt.
-   **Styling**: Vanilla CSS with Modern Layout Utilities (Grid/Flex).

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### 1. Clone the repository
```bash
git clone https://github.com/your-username/clubhub.git
cd clubhub
```

### 2. Setup Backend
```bash
cd backend
npm install
# Create a .env file and add your JWT_SECRET and GOOGLE_CLIENT_ID
npm start
```

### 3. Setup Frontend
```bash
cd ../frontend
npm install
npm run dev
```

## 🎨 Design Philosophy
The project follows a **"Glass-Brutalist"** design language:
- **Bold Geometry**: Thick black borders and high-contrast shadows.
- **Glassmorphism**: Frosted glass panels (`backdrop-filter`) for content cards.
- **Motion-First**: Every interaction is animated using `framer-motion` to create a living, breathing interface.
